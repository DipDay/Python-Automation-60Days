# Day 22 — Project 3: Excel Report Generator

## Overview
An automated Excel reporting system built with Python, Pandas, and OpenPyXL.

This project reads raw sales data, analyzes it, and generates a professionally formatted Excel report automatically.

## Features
- Sales Data Analysis
- Total Sales Calculation
- Top Products Analysis
- Monthly Sales Analysis
- Summary Report Generation
- Excel Charts
- Automatic Column Formatting
- Multiple Excel Worksheets
- Dynamic File Path Handling using pathlib

## Technologies Used
- Python
- Pandas
- OpenPyXL

## Project Files
- `main.py` — Main automation script
- `sales.xlsx` — Input sales dataset
- `sales_report.xlsx` — Generated Excel report

## How to Run

Install dependencies:

```bash
pip install pandas openpyxl
```

Run:

```bash
python main.py
```
